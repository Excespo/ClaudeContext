# 分析工具箱：这些对话里反复用到的同一台机器

## 核心动作：抓住「干太多活」的词，把它劈开

回顾这些讨论会发现一个反复出现的操作——每当卡住，就找出一个含混地打包了两样东西的概念，拆开它，看冲突消失：

| 被劈开的词 | 劈成 |
|---|---|
| 腐蚀 | 能力饱和型犯规 / 图利型犯规 |
| 观众 | 审美善的消费者 / 部落认同善的消费者 |
| 体育 | askēsis / 竞技 / 商业奇观（三种 telos） |
| 立场 | 道德的外敌 → 道德分析的内部变量 |
| 公共讨论 | 公共领域 / 制度程序 / 权利 |
| 情绪 | 体验 / 评价判断 / 对他人的索求 |
| 「优先」 | 条件优先 / 因果优先 / 起点优先 |

**表面的矛盾往往不是被论证消灭的，而是被一个区分溶解的。**

## 这台机器的师承

方法是复合的：**概念分析 + 反思平衡（拿原则去撞具体案例的直觉，两头都可微调）+ 牛津式的区分绘制**。

- 拆词这门手艺：G.E. Moore（自然主义谬误就是一次经典拆词）→ 后期维特根斯坦 → **牛津日常语言学派**（Ryle、J.L. Austin）：别问这个词的定义，看它在做什么工作
- 反思平衡：Rawls
- 领域：分析进路的道德哲学，横跨规范伦理学与元伦理学

## 三判据：什么时候「我是刻意的」不能作为辩护

场景：水平差的通俗小说作者把失真辩护为「我是刻意的」。看似不可证伪，其实弱点明显。

**第一刀：意图谬误**（Wimsatt & Beardsley 1946）。作品的成败判据在文本内部。即便让步承认「确实刻意」，批评也丝毫不减损——刻意写出的失败仍是失败。可用格式：**「我批评的不是你想做什么，是你做成了什么。」** 意图只有被实现为形式（achieved intention）才进入审美账目。

**第二刀：三判据。** 用立体主义作参照——它对透视的偏离比印象主义更激进，但仍然正当，因为它同时满足：

1. **形式宣告**：偏离必须由作品**自身**高声宣告。没人会把分析立体主义误读为写实失手。宣告必须**在文本内**完成；事后在访谈里补一句「我是刻意的」等于**追溯性改写契约**。而以写实语域写作（真实都市、职场、当代人际）的小说，签的是逼真性契约
2. **系统性**：偏离要服从一个统一原理（立体主义的每处变形都服从多视点同时性）。无能的标志恰恰相反——偏离是随机的：人性在需要推进爽点时扁平、不碍事时又忽然正常。**「你的偏离没有语法，只有漏洞」**——刻意是可以留下文本证据的；无法与失手在证据上区分开的「刻意」不具辩护效力
3. **兑换物**：偏离必须在**做工作**。反透视换来了认知的同时性。致命一问是：**你的失真买到了什么？**

## 一个常见的经济学谬误（顺带记下）

**劳动总量谬误（lump of labor fallacy）**：「岗位总量固定，人少了所以人均机会多」。人口下降同时萎缩总需求、市场规模与企业数量，岗位不是固定的蛋糕。

不过日本这个自然实验给了「人口下降 → 就业市场宽松」部分支撑；而真正被现实反驳得最彻底的是另一环——**「竞争/教育强度会随之下降」**：东亚低生育率地区的教育竞争并未随出生人口下降而缓解，因为竞争的标的是**相对位置**而非绝对名额。
