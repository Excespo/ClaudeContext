# 希腊神话：三条正交的轴

## 先纠分类错位

「半神」是**谱系范畴**（父母一方为神），「史诗人物/剧作人物」是**文本载体范畴**——不是并列的。赫拉克勒斯是半神，也是索福克勒斯《特拉基斯少女》与欧里庇得斯《赫拉克勒斯》的主角；奥德修斯不是半神（曾祖是赫尔墨斯，血缘太远），却横跨史诗与悲剧。

## 轴一：神话谱系（世代序列）

早期英雄代（珀尔修斯、赫拉克勒斯、伊阿宋、忒修斯）→ **忒拜循环**（卡德摩斯 → 拉伊俄斯 → 俄狄浦斯 → 七雄攻忒拜 → 厄庇戈诺伊 → 安提戈涅一辈）→ **特洛伊循环**（阿喀琉斯、奥德修斯、阿伽门农）→ **诺斯托伊/返乡**（《奥德赛》与阿特柔斯家血案 → 《俄瑞斯忒亚》）。

**缝合线才是古人当作连续史处理的证据**：赫拉克勒斯早特洛伊战争一代，曾攻陷拉俄墨冬的特洛伊，他的弓传给**菲罗克忒忒斯**（没有这把弓特洛伊攻不下来）；忒拉蒙是他的战友，其子大埃阿斯战于特洛伊；**狄俄墨得斯**最干净地跨循环（先作为厄庇戈诺伊攻下忒拜，再是《伊利亚特》第 5 卷主角）；涅斯托尔活三代，功能就是把早期英雄代的记忆带进特洛伊。

## 轴二：文本载体（同一人物在不同文类中变形）

重复不但存在，而且**形象常常逆转**：

- **奥德修斯**：荷马的 πολύτροπος 多智者 → 索福克勒斯《菲罗克忒忒斯》《埃阿斯》、欧里庇得斯《赫卡柏》里的诡辩政客，几乎是反派。公元前五世纪雅典对「能言善辩」的政治疑虑直接投射了进去
- **赫拉克勒斯**：泛希腊救世英雄 → 欧里庇得斯手中的杀妻杀子者，甚至阿里斯托芬的馋嘴丑角
- **伊阿宋**：品达笔下尚可 → 欧里庇得斯《美狄亚》里的背信者，且**几乎没有崇拜地点**

## 轴三：崇拜（英雄祭仪）

道德估值与崇拜规模并不同步。大埃阿斯在《奥德赛》第 11 卷沉默转身，在萨拉米斯却有极高规格的 Aianteia，雅典还有 Aiantis 部族；阿喀琉斯在黑海白岛被作为 Pontarches 崇拜；狄俄墨得斯的崇拜集中在**意大利**。

## 奥德赛 vs 尤利西斯

**同一个人的两套名字**：Ὀδυσσεύς → 西希腊/西西里方言 Οὐλίξης → 伊特鲁里亚 Utuze → 拉丁 Ulixes/Ulysses。d/l 交替是借词链的痕迹。

**但接受史已经分化出不同人格**：希腊传统的 Odysseus 叙事引力指向「回家」；拉丁—基督教传统的 Ulysses 被但丁（《地狱篇》XXVI）重写为**越界者**，为求知冲出赫拉克勒斯之柱而覆舟，丁尼生的 *Ulysses* 再把这种不安分转成维多利亚式的英雄意志。**所以乔伊斯选 "Ulysses" 而非 "Odysseus"，本身就带着但丁—丁尼生这一脉的流放意涵，而非单纯的荷马归乡。**

## 《奥德赛》航程的结构事实

24 卷里真正叙述漂泊的只有第 **9–12 卷**（Apologoi），且是奥德修斯在费埃克斯人宫廷上的**第一人称回忆**；史诗从第七年的俄古癸亚岛切入（in medias res），前四卷是「忒勒马科斯纪」。**航程是嵌套叙事，不是主线时序。**

序列：伊斯玛罗斯（贪与不听劝）→ 食莲族（遗忘之诱）→ 波吕斐摩斯（Οὖτις 之计，但离岛报出真名招致波塞冬之怒，**这是全诗的因果引擎**）→ 风袋（已望见炊烟而功亏一篑）→ 莱斯特律戈涅斯（毁十一船）→ 喀耳刻 → **第 11 卷 Nekyia 冥府招魂（全诗结构中心）**→ 塞壬 → 斯库拉与卡律布狄斯（明知必损六人的领导抉择）→ 特里那基亚（宰食圣牛，全员覆没）→ 卡吕普索（拒绝不朽，选择有死的人性）→ 斯刻里亚。

**叙述可靠性**：这段自述无人证实，而他随后对欧迈俄斯连讲数个「克里特谎言」——这是学界持续的议题。

## 海伦：跨度最长的人物

- **出生之前**：《塞浦路斯之歌》残篇——大地不堪人口重负，宙斯策划特洛伊战争以减负。**海伦从设定之初就不是「引发」战争的人，而是被造出来执行灭绝的手段**
- **两个诞生版本**：尼墨西斯版（较古，母亲是「报应」本身，把工具属性写进血统）/ 勒达版（通行，「分裂父权」：海伦与波吕丢刻斯属宙斯而不死，克吕泰涅斯特拉与卡斯托尔属廷达瑞俄斯而有死）
- **姐妹关系锁死两个循环**：海伦与克吕泰涅斯特拉是姊妹，嫁给墨涅拉俄斯与阿伽门农两兄弟
- **童年被忒修斯劫持**，托付给其母**埃特拉**看管；双子星救回并掳走埃特拉充作侍女 → **深处伏笔**：《伊利亚特》第 3 卷海伦在特洛伊城墙上，侍女中就有埃特拉。荷马未加解释，说明听众早已知晓
- **埃及岔路**（斯特西科罗斯的 palinode → 希罗多德 → 欧里庇得斯《海伦》）：去特洛伊的是幻影，本人一直在埃及

值得做的切法：按文本源出处重排（荷马 / 已佚的史诗循环残篇 Cypria·Little Iliad·Iliupersis·Nostoi / 抒情诗与悲剧的增补 / 希腊化—罗马追加），可以看清每个环节的**证据强度**。
