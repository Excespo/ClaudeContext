# humanities：哲学与社会理论

## 目标
把零散的兴趣阅读变成可检索的论证地图：谁主张什么、靠什么论证、最强反驳是什么。

## 硬约束
- 每篇 note 必须包含：论点 / 论证结构 / 关键概念的原文术语（含原语言）/ 最强反驳
- 二手文献的转述必须标明来源，不要把导论书的概括当成原著主张
- 术语用原文（signifiant / signifié、Dasein、剩余价值 Mehrwert），中译名放括注
- 不做「某某其实是想说」这类未经文本支撑的重构

## 目录
- `notes/philosophy/` 伦理学、认识论、现象学
- `notes/theory/` 社会理论与批判理论（马克思、结构主义、精神分析、后现代）
- `notes/literature/` 文学与艺术的具体分析
- `notes/method/` 方法论与推理工具（贝叶斯 vs 频率学派的实际分歧、论证结构分析）
- `sources/` 原文与译本节选，保留版本与页码
