# 训练认知 ladder

当前阶段：**L1 进行中**（2026-09-13 初始化）

## L1 看懂
- [ ] 肌肥大的三个常被引用的驱动因素及其争议（机械张力 / 代谢压力 / 肌肉损伤）
- [ ] 主要动作模式的关节力学：推、拉、铰链、蹲、搬运
- [ ] 容量（sets × reps × load）与力竭距离（RIR）的基本关系
- [ ] 有氧的供能系统切换与呼吸节奏

## L2 会排
- [ ] 给自己写 8~12 周的周期化方案并说明每个变量的进阶规则
- [ ] 按弱项选动作：力臂、肌纤维走向、活动度限制怎么影响选择
- [ ] 力量与有氧同期训练的干扰效应及安排顺序

## L3 会调
- [ ] 从训练日志里识别疲劳累积与进步停滞，并给出减载方案
- [ ] 伤后（如踝关节韧带）渐进负荷的判据与替代动作链
- [ ] 分辨网络内容里的伪机制说法，能指出它的证据缺口
