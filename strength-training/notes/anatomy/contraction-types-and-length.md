# 向心/离心/等长，与「拉长位」是两个维度

## 定义

| | 肌肉长度 | 是否产生张力 |
|---|---|---|
| 向心 concentric | 变短 | 是 |
| 离心 eccentric | 变长 | 是 |
| 等长 isometric | 不变 | 是 |
| 被动拉伸 passive stretch | 变长 | **否** |

生理学里的 contraction 指**激活并产生张力**，不是「变短」。所以离心也是收缩——肌肉正在用力，只是外力更大把它强行拉开。压腿时的静态拉伸才是「拉伸」。

判据不是「我在推还是在放」，而是肌肉力矩与外部力矩谁更大。可测推论：force–velocity 关系决定 **离心最大力 > 等长 > 向心**，离心峰值约为向心的 1.2–1.5 倍——这就是为什么你能慢慢放下一个根本举不起来的重量。

## 长度区间 ≠ 收缩类型（最容易错的一步）

把手臂举到过顶，对三头长头是「被动置于长位」，**不是离心**：

- 举到过顶：肩屈曲由三角肌前束等完成，长头只是被带到更长的位置（titin 与结缔组织的被动张力）
- 组内做次数时：肩角度不变，长头在肩端的长度是个常数偏移，既不向心也不离心
- **真正的离心发生在肘**：重量下放、肘屈曲，长头在肘端被拉长且在抗阻

所以 Maeo et al. 2023 里过顶臂屈伸对长头多出的肥大，来源**不是「更多离心」，而是整组动作的肘关节 ROM 被平移到更长的肌节区间上**——同样的向心、同样的离心，只是发生在长度轴更靠右的位置。

可验证推论：在过顶位保持不动，长头是等长，不是离心，尽管它此刻很长。

双关节肌的被动不足（passive insufficiency）：长头无法在两个关节同时被拉到极限。过顶 + 肘完全屈曲已接近其可用长度上限，这既是底部拉伸感特别强的原因，也可能是肘不适的原因——**判据：减小肩屈曲角度（改用上斜凳靠背）后不适消失，说明是长度问题而非肘关节本身**。

## 不要专门加「离心训练」

离心造成更多损伤与 DOMS，但损伤不是肥大驱动因素（见 [[../programming/hypertrophy-drivers]]）。eccentric-only vs concentric-only 的肥大差异很小、方向略偏离心但不稳健。正常做完整 ROM 的组两个阶段都包含了。真正值得控制的只有一条：**别让离心阶段自由落体**，那部分张力时间是白送的。

## 后侧链

posterior chain 是训练用的功能性概念，不是解剖学正式结构：足底筋膜 → 腓肠肌/比目鱼肌 → 跟腱 → 腘绳肌 → 臀大肌 → 竖脊肌/多裂肌 → **胸腰筋膜**（关键的力传递枢纽，连接臀大肌与对侧背阔肌）→ 背阔肌。串成链的机制是髋伸：臀大肌与腘绳肌产生髋伸力矩，经胸腰筋膜传到躯干。

有用的推论——链上的成分不可互换：
- 髋主导（RDL、早安、髋推）偏髋伸，练到 BFlh 的拉长位；膝主导（腿弯举）偏膝屈，更多 semitendinosus
- 腓肠肌跨膝、比目鱼肌不跨 → 直腿提踵练前者，**屈膝**提踵/拉伸练后者
- 硬拉底部腘绳肌在髋端被拉长、在膝端接近伸直，正是最易拉伤的位置（Nordic curl 的价值在此）

**反对意见**：这个词常被当成「练背面就行」的模糊借口。同一条链上，坐姿腿弯举与 RDL 对 BFlh 的效果差别很大（Maeo 2021）。选动作时该问的还是那两个问题：**目标肌肉被放在什么长度、阻力力矩峰值落在哪。**

## 山羊挺身练到哪

练的是**竖脊肌腰段**，但它本质是**髋伸动作**：主要发力方是臀大肌与腘绳肌，竖脊肌在标准做法里是**等长收缩**（绷紧固定腰椎、把上半身当一根硬杠杆），而不是靠腰椎反复弯伸抬起身体。
正确形态的感觉是持续紧绷酸胀，不是一节一节卷起来。检验：做组时按住腰椎两侧的隆起，全程应该是硬的；第二天臀与腘绳肌后侧酸、下背轻度紧张 = 做对了，只有下背剧烈酸痛而臀腿没感觉 = 腰在代偿。顶部别过度后仰挺腰（腰椎过伸挤压关节突，是这个动作最常见的疼痛来源）。
